Key Linux Hardening Checklist
Update & Patch: Regularly apply security updates (apt update && apt upgrade or yum update) to fix vulnerabilities.
Minimize Services: Disable or uninstall unnecessary services, software, and packages to reduce potential entry points.
Secure SSH: Modify /etc/ssh/sshd_config to disable root login (PermitRootLogin no), change the default port, and use SSH key-based authentication.
Firewall Configuration: Enable and configure firewalls (UFW or firewalld) to allow only necessary traffic.
User Management: Enforce strong password policies, lock unused accounts, and ensure users use sudo instead of root.
File System Security: Use separate partitions for /var and /home, set restrictive permissions, and utilize tools like SELinux or AppArmor.
Monitoring & Logging: Configure rsyslog to send logs to a remote server for integrity and auditability.
